# Aventuras del Tío Pelón 🎮

Juego de plataformas 2D creado para ejecutarse directamente en el navegador.

## Controles
- PC: `A/D` o `←/→` para moverse.
- `W`, `↑` o `Espacio` para saltar.
- Móvil: botones táctiles en pantalla.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `style.css` y `game.js` a la raíz.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama principal y la carpeta `/ (root)`.
6. Guarda y abre la URL de GitHub Pages que GitHub te mostrará.

No necesita servidor ni librerías externas.

## Nueva versión
- Enemigo volador: **Chancla Voladora**.
- Se mueve de lado a lado y cambia de altura.
- Puedes derrotarla saltando encima; si te golpea, pierdes una vida.

## Compañero
- Se agregó el conejito de la imagen proporcionada como compañero del Tío Pelón.
- Sigue al protagonista, salta obstáculos y puede recoger monedas y estrellas.

## Dificultad progresiva y jefes
- Cada nivel aumenta la velocidad y cantidad de enemigos.
- Al final de cada nivel aparece el **Villano Pupusas** como jefe.
- El jefe tiene más vida en cada mundo y lanza proyectiles.
- Para terminar el nivel hay que derrotar al jefe antes de cruzar la meta.

## Mundos
1. 🌲 Bosque
2. ❄️ Nieve
3. 🏜️ Desierto
4. 🏙️ Calle

La dificultad aumenta de un mundo al siguiente.
